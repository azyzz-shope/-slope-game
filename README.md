# SLOPE — AZIZ

A browser-based 3D endless runner built with Three.js.

## Play
Enable GitHub Pages for this repository:
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Open the Pages URL shown there.

## Controls
- **A / D** or **Left / Right arrows**: steer
- Avoid the red blocks and stay on the track.
- Secret bonus: press **R + J together** during a run to add 1,000 points.

Three.js is loaded from jsDelivr, so an internet connection is required.
